# Editable Content

The manager should write owner-editable copy and image paths here.

- `site.json` controls page copy, SEO text, business details, and editorial headings.
- `menu.json` controls menu groups.
- `editorial.json` controls homepage/menu photography and image metadata.

Uploaded images should be committed under `public/assets/uploads/` and referenced from JSON with a path like `/assets/uploads/example.jpg`.
